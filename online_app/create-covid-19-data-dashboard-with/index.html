Problem Definition

The COVID-19 pandemic has put a significant strain on hospitals worldwide. The goal of this project is to create a data dashboard to track hospital performance and provide insights on the geographic distribution of COVID-19 cases.

  • Key questions to answer:
    • What is the current trend of COVID-19 cases globally?
    • How do hospital capacities vary by region?
    • What are the weekly and monthly changes in COVID-19 cases?
  • Success metrics / KPIs:
    • Number of COVID-19 cases
    • Hospital capacity utilization
    • Weekly and monthly changes in COVID-19 cases
