# Expense Tracker App

This is a simple mobile app built using Kivy that allows users to manage their personal expenses.

## Setup and Run

1.  Install the required dependencies by running `pip install -r requirements.txt`
2.  Run the app by executing `python main.py`
3.  The app will launch and display the login screen.
4.  Register a new user by clicking on the "Register" button and filling out the registration form.
5.  Login to the app using the registered username and password.
6.  Once logged in, you can add expenses by selecting a category and entering an amount.
7.  View all expenses by clicking on the "View Expenses" button.

Note: This is a basic implementation and does not include any error handling or security measures. It is meant to serve as a starting point for building a more robust expense tracking app.
