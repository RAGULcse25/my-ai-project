# BMI Tracker

A simple BMI tracker application built with Flask and SQLite.

## Setup

1. Create a virtual environment: `python -m venv venv`
2. Activate the virtual environment: `source venv/bin/activate` (on Linux/Mac) or `venv\Scripts\activate` (on Windows)
3. Install the dependencies: `pip install -r requirements.txt`
4. Run the application: `python app.py`

## Features

* Create, read, update, and delete users
* Search and filter users by name and health status
* Paginate users
* Display user data in a table

## API Documentation

* `GET /`: Returns a list of all users
* `POST /create`: Creates a new user
* `GET /update/<int:user_id>`: Returns a user by ID
* `POST /update/<int:user_id>`: Updates a user by ID
* `DELETE /delete/<int:user_id>`: Deletes a user by ID
* `GET /search`: Searches for users by name
* `GET /filter`: Filters users by health status
* `GET /paginate`: Paginates users
