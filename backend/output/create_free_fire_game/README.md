# Free Fire Game
## Description
Free Fire is a space shooter survival game with a military gritty theme.
It is built with 14 AI agents for enhanced gameplay.

## Features
* Space shooter gameplay
* Survival mode with limited resources
* Military gritty theme and graphics
* Shotgun as primary weapon
* Multiplayer support with AI agents
* Regular updates with new features

## How to Play / Use
1. Launch the game and select your preferred mode.
2. Use your shotgun to defeat enemies and survive.
3. Gather resources to upgrade your equipment and stay alive.
4. Compete with other players to achieve the highest score.
