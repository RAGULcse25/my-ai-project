This project is designed to explore machine learning and API development using Python, FastAPI, scikit-learn, pandas, and Streamlit.

## Introduction
This project uses a combination of machine learning and API development to create a robust and scalable application.

## Getting Started
To get started with this project, clone the repository and navigate to the project directory. Install the required packages using `pip install -r requirements.txt`.

## Project Structure
The project consists of the following files:
- `main.py`: The main application file.
- `model.py`: The machine learning model file.
- `data_loader.py`: The data loading file.
- `requirements.txt`: The requirements file.
- `README.md`: This documentation file.

## Tasks
The project is divided into the following tasks:
1. **Task 1: Load and clean dataset**: Load the dataset and clean it for use in the machine learning model.
2. **Task 2: Train ML model**: Train the machine learning model using the cleaned dataset.
3. **Task 3: Build API endpoint**: Build an API endpoint to interact with the machine learning model.
4. **Task 4: Create frontend UI**: Create a frontend UI using Streamlit to interact with the API endpoint.
5. **Task 5: Write documentation**: Write documentation for the project.

## Requirements
The project requires the following packages:
scikit-learn
pandas
numpy
fastapi
streamlit
uvicorn

## API Endpoints
The API has the following endpoints:
- **/predict**: Make a prediction using the machine learning model.
- **/train**: Train the machine learning model.

## Frontend UI
The frontend UI is built using Streamlit and provides a simple interface to interact with the API endpoint.
