# Chess Game
## Description
Create a chess game with AI opponents and customizable settings.
Built with 14 AI agents for a robust and engaging experience.

## Features
* Play against Computer AI with adjustable difficulty
* Choose from various board themes, including Classic wood
* Enable move hints for improved gameplay
* Easy, Medium, and Hard difficulty levels
* Customizable game settings and preferences
* Built with 14 AI agents for advanced game logic

## How to Play / Use
1. Select your preferred game settings, including AI difficulty and board theme.
2. Start a new game and make your moves on the board.
3. Use move hints to guide your strategy and improve your gameplay.
4. Adjust your settings and preferences as needed to enhance your experience.
