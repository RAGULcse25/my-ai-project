# 3D Car Game
## Description
Create a 3D car game with a side-scrolling feature on a race track set in a neon night city. The game includes a lives system and is built with 14 AI agents.

## Features
* Side-scrolling gameplay
* Race track environment
* Neon night city theme
* Lives system for player health
* AI-powered game logic
* Customizable frontend layout

## How to Play / Use
1. Launch the game and select your vehicle.
2. Navigate the race track using the side-scrolling feature.
3. Collect power-ups to increase your lives and score.
4. Compete against AI opponents to achieve the highest score.
